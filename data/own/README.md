# Собственное видео

`own.avi` — ролик для проверки трекера на объекте, которого нет в тестовом
наборе.

- Объект: плоская картина с ярким граффити (холст на стене).
- Размер: 640×360, 23.976 fps, 144 кадра.
- Сценарий: первый кадр — крупный план картины, затем плавный отъезд
  камеры, картина уменьшается и открывается окружающая стена.

В среде выполнения не было веб-камеры (`/dev/video*` отсутствует), поэтому
ролик собран программно из свободного стокового клипа Pexels
[`7950037`](https://www.pexels.com/video/7950037/): из кадров вырезана
область с картиной и построен плавный отъезд. Это единственное отличие от
«снятого вручную» видео; для алгоритма важны только изображения, а не
способ их получения.

Запуск трекера:

```bash
uv run track data/own/own.avi -o results/lab2/own_tracked.mp4 --label "Painting"
```
